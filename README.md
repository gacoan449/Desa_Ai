# Desa AI

AI chat and API reseller platform starter for DesaPay.

This repository hosts a standalone Flutter + Firebase application with a familiar AI chat workspace, server-side usage billing in IDR, optional web search, plugin catalogue, and Tripay top-up integration.

## Status

- UI: prototype/starter implementation.
- AI models: configure real provider model IDs and price rates in Firebase secret/config before production.
- Tripay: requires merchant credentials and callback verification testing.
- Never put provider secrets in Flutter.
